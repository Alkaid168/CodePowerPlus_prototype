# 采集助手使用与卸载

1. **安装**：当前将`output/collector/codepowerplus-collector-0.4.6.zip`解压到固定目录，在Edge/Chrome扩展管理页开启开发人员模式并加载该目录。更新时覆盖原目录、点“重新加载”并重开任务页，不必卸载，保留原任务。商店上架后改为点“安装”。
2. **登录**：在同一浏览器个人资料中正常登录四个平台，保持原站标签页打开；不需要复制cookie或把OJ密码交给本系统。
3. **采集**：打开扩展，逐站“授权并识别账号”，选择是否采源码，再开始。可以暂停/恢复；原站要求验证时在原标签页处理。AtCoder仅快速模式向kenkoooo.com查询公开账号的提交副本（含练习），再从官网取源码；副本可能滞后/漏收。0.4.6起不再提供逐比赛扫描或比赛编号入口。
4. **保存**：任务结束或暂停后预览记录，选择导出JSON，或有本站服务时输入服务器地址及短期导入令牌，勾选同意后上传。当前没有服务器也可以采集并导出。
5. **核对**：导出后打开文件确认`batches`中记录数和需要的源码；上传需等到“服务器已确认接收…条记录”。看到本地预览或只上传了几批都不代表保存完成。
6. **卸载**：完成核对即可卸载。服务器记录与独立导出文件保留，扩展本地记录和断点随卸载清除。以后需要同步，再安装并重新授权即可；重装后重新采集，服务器按提交ID更新，不增加同一条提交。

本地采集断点和上传断点均可跨页面/浏览器重开保留。上传令牌不持久化，过期后重新获取；换服务器或重新采集后不能误用旧上传计划，可清除本地上传进度再传。

提交时间在扩展中按UTC+8显示；JSON里的`submitted_at`仍为UTC（末尾`Z`），例如`00:00Z`对应界面的`08:00`，是同一时刻。

旧版AtCoder逐场扫描任务：先暂停，更新后点击任务旁“改用快速采集”，允许访问AtCoder Problems即可。原本地记录保留；仅公开账号名用于查询，不发送OJ凭据。快速模式完成不代表官网全量，副本失败会保留数据暂停，不退回逐比赛扫描。

清理多余任务：点任务旁“删除本地任务”并确认，将删除该任务本地记录、源码和上传断点，无法撤销；其他任务、服务器已接收数据和独立导出文件保留。未备份时先导出，不能把删除任务当作单纯隐藏卡片。

源码“不可取/无权限/仅图片”等状态会保留，当前四站真人全量验收尚未完成，页面显示“可见范围已遍历”不证明平台隐藏或已删除记录也已取得。

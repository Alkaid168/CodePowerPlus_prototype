# AtCoder快速提交采集

- 用户反馈官网逐场扫描大量空比赛，要求保留未参赛的练习提交；不使用参赛/评级历史限制范围。
- 新增用户授权的快速模式：AtCoder Problems公开提交副本批量元数据（每页最多500），本人源码仍用官网已登录标签页。公开账号名发送给kenkoooo.com，OJ cookie/密码不发送；副本可能滞后/漏收，UI及导出明确标注来源，完成不等于官网全量。
- 时间范围固定在任务创建时；先/后计数核对，每满页验证末秒计数再推进，无法消除同秒截断则暂停，不静默跳秒。每次请求沿用串行限速、断点事务。
- 指定比赛/官网归档扫描保留；旧归档任务暂停后可显式改快速模式、保留本地记录，并在范围中说明可能混有原官网记录。
- 新增API/引擎回归先红后绿，测试练习记录、分页边界、对账失败、来源标注、不泄露凭据；隔离Edge验证授权后实际worker链路。更新说明、长期记录及版本包。

# 题目分析置信度诊断（2026-10-16）

## 结论

现存 public40 输出的**整体自报置信度并不低，平均 93.78%**。此前的 **0.580 是预测标签与辅助参考的 micro F1，不是模型置信度，也不是“58% 的题分析正确”**。更需要解决的是：模型常常很有把握，却多贴标签、漏掉有效解法，偶尔把简单问题过度复杂化。

本报告只读取离线结果与当前代码，未重新调用模型、修改提示词或读写正式数据库。结果来自 2026-10-05 的 `deepseek-chat / problem-analysis-v5`；不能代表今天重新调用的结果。标签参考由代理生成，未经教师或双人独立审核，不是人工金标准。

## 1. 实际数值：先分清三类指标

数据：`data/evaluation/public40/run-2026-10-05/{predictions,manifest,report}.json`。按来源 URL 对齐 40 题，置信度统计只取 `predictions.json` 的模型输出，未混入 manifest 中参考答案自己的置信度。

| 对象 | 数量 | 平均 | 中位数 | 最低—最高 |
| --- | ---: | ---: | ---: | ---: |
| 全部题的整体 confidence | 40题 | 93.78% | 95% | 85%—100% |
| 洛谷整体 confidence | 20题 | 93.50% | 95% | 85%—100% |
| CF 整体 confidence | 20题 | 94.05% | 95% | 85%—100% |
| 全部 knowledge_confidence | 106个预测标签 | 85.54% | 90% | 30%—100% |
| 洛谷标签 confidence | 58个 | 84.45% | 90% | 30%—100% |
| CF 标签 confidence | 48个 | 86.85% | 90% | 50%—100% |
| 主标签 confidence | 61个 | 92.90% | 95% | 70%—100% |
| 次标签 confidence | 45个 | 75.56% | 80% | 30%—95% |

标签行按每个预测标签等权统计，并非先算每题平均。14 个置信度不超过 60% 的标签全部是次标签；整体分数中 26/40 恰为 95%。因此，局部的低数值主要出现在“也涉及”标签，并非整份分析普遍没有把握。

辅助参考共有 70 个标签，预测 106 个；严格按 ID 比较，共重合 51 个、多出 55 个、缺少 19 个：precision=48.11%，recall=72.86%，micro F1=57.95%，整组标签完全一致 6/40。只比较主标签的 F1=65.00%。这些是**参考一致性**，每个 extra 不能自动判为真正误标。CF 官方评分对照为 MAE=140、16/20 误差不超过 200；它也是另一项指标。

## 2. 数字从哪里来，系统有没有把它压低

- `app/services/analysis.py` 要求模型自己填写整体 `confidence` 和逐标签 `knowledge_confidence`；它们是生成的 JSON 数值，不是模型 token 概率、重复实验投票率或人工验收率。
- `app/schemas.py`、`app/knowledge.py` 与服务层主要校验范围、ID、证据及字段完整性；`validate()` 不重新计算或校准置信度。整体值也没有由标签均值或最低值汇总的公式。
- `app/repositories.py` 保存并返回 payload；`app/static/js/views/analysis.js` 的 `percent()` 只做乘 100、四舍五入。未发现这条显示链把模型数值打折。人工编辑默认值 0.8 是另一来源，不能混作模型测量。
- 若看到的是**能力画像**里的置信度，来源另为 `app/services/profile.py` 的 `n/(n+5)`，n 是该知识点所关联的有效独立题目证据数。只有 1 题时为 16.67%，5 题为 50%；这是证据数量启发式，不是本次分析 confidence。本报告未查询当前学习记录，不能断言用户看到的就是这一项。

## 3. 已证实的问题与原因假设

### A. 标签扩展口径与严格参考存在张力

当前提示词同时要求“所有说得通的解法涉及的知识点都要标出来”“宁可多标一个确实用得到的知识点”，又要求依据“解题所必需的知识”。多解法要求应保留；问题是模型把“可行解法中的关键知识”扩展成“相关概念、算法内部操作甚至不满足完整规模的朴素思路”。

**已观察到的例子：**455A 把 DP 的前缀最优值称作“前缀和”；520B 把反复除以 2 作为“二分”的依据；P1055 把余数 10 写作 X 标成“位操作”（30%）。这些证据不足以支持对应算法标签。P1115 还列出 O(n²)/O(n³) 枚举作为理解起点，并据此加标签；理解起点不等于可通过完整约束的另一解法。

**合理推测：**提示词的扩展倾向促进了次标签数量和低置信候选；但没有做提示词消融实验，不能量化它造成了多少多标，更不能把全部 55 个 extra 都归因于它。

### B. 参考也可能不完整，F1 会惩罚有效备选方案

P1047 模型给排序合并区间标签 60%，其方案在 m≤100 时可行；辅助参考只列模拟与差分，故排序被统计为 extra。这是**低分但有合理依据**的标签；60% 可能反映它对“该不该纳入标注”的犹豫，不能直接解释成方案只有 60% 正确。

同题模型漏了参考中的差分；P1020 的树状数组备选方案也不能仅因参考未列出就判错。现行 exact-ID 指标不会自动识别语义重叠、粒度或参考覆盖不足。需人工逐项裁定后，才能区分模型错误和标注口径差异。

### C. 高置信仍会判断偏离：50A

50A 的模型整体 confidence=90%，状压 DP=90%、轮廓线 DP=85%，给 difficulty=1500；采集的 CF 官方评分为 800。题目只求无障碍矩形能放的最多 1×2 骨牌数，答案是 `floor(M*N/2)`，可用面积上界和配对铺设证明。

DP 可以解决该问题，但它不能支撑“需要轮廓线/状压 DP”的难度理由；模型把可用的复杂方法误当成必要知识，缺失简单主线。这里证明的是**高自信不保证题目分析恰当**，不意味着 DP 本身不能算出答案，也不证明所有高置信输出都错。

### D. 缺参考材料、题面重述与模型能力：还需要对照

`app/public_problem_batch.py::predict_batch()` 仅传重述题面、词表与设置，没有传 manifest 的辅助参考；40 题均未提供参考题解/代码。提示词要求信息不足时降置信度，但本批整体仍很高。参考材料可能帮助约束解法和复杂度，现有数据不能证明“未提供参考”就是低分或误标的主因。

公开经典题记忆、题面改写、模型算法推理能力都可能影响结果；没有同题对照或训练数据证据，不能分别归因。前端 LaTeX 显示与模型读取原文是两条链路；本轮没有证据证明排版问题造成当前 confidence 或 F1，不能以修好公式显示代替模型质量验证。

## 4. 文献支持什么，不支持什么

[Lin、Hilton 与 Evans，2022](https://arxiv.org/abs/2205.14334) 表明，GPT-3 经相应训练后可以用文字表达经过校准的不确定性。这说明数字有可能有用，条件是要做训练或实证验证。

[Tian 等，EMNLP 2023](https://aclanthology.org/2023.emnlp-main.330/) 在其测试模型与问答基准上发现，口头表达的置信度通常比模型条件概率更校准，且提问方式会影响结果。这些结论不能直接转成“当前 deepseek-chat 的 95% 就是 95% 正确率”：模型、任务、标注目标和提示词均不同。

本项目整体 confidence 的“整体正确”尚未定义：思路正确、难度误差≤200、标签完全一致分别是不同事件。**不能拿 93.78% 整体 confidence 减去 57.95% F1，就宣称测出了校准误差。**

## 5. 下一步实验建议（未执行）

1. **先核实用户所指页面与具体数值。** 区分整体分析、单标签、画像证据置信度及评估 F1；保留原始预测作为基线。
2. **先建人工参考和错误分类。** 对 public40 的 extra/missing 逐项由人核对，尤其标记“错误标签／有效备选解法／粒度差异／参考遗漏”；另补未公开学校题，由两人独立标注并仲裁。保留多种可行解法，不通过强制少标来美化分数。
3. **授权后做小规模对照。** 固定题集、模型和词表，对比原提示词与“各备选解法须满足完整约束、有具体算法步骤，并区分必要知识与一般实现细节”的提示词；另做无参考/有可靠参考对照。修改前先展示完整系统提示词。分别报告有效解法覆盖、误贴标签、漏标、难度误差、成本与校验重试，不能只看 confidence 是否升高。
4. **最后校准。** 明确逐标签事件为“人工认可该题应包含该标签”，在独立留出集看置信分箱与实际认可率；有足够样本再评估 ECE/Brier、风险与覆盖率。只有已选标签的置信度只能帮助研究误标风险，漏标还需单独量召回。现有40题和代理参考不足以产出可靠生产阈值。

验收目标是“同等有效解法覆盖下减少误标、低把握能识别高风险”，不是把提示词改成一律自报 95% 以上。

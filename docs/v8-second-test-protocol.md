首测实际请求deepseek-chat、temperature=0、JSON输出，没有thinking和reasoning_effort。响应为deepseek-flash；usage的completion_tokens_details为空，未留reasoning_content，不能倒推其实际思考强度或断言Low。

## 标签与题解的复核

20题参考标准在读取二测结果前形成，见v8-second-test-review-rubric.md及reference-checks.json。标准依据题意和有效解法，允许多个合理算法，不能将原站标签当唯一答案，也不要求穷举所有可行解法。

每份最终分析分别记录tags_correct与solution_correct原生布尔及具体依据。题解需主线可行、正确性理由成立、复杂度与范围合理、关键边界不遗漏；标签应覆盖其声称方法的关键知识，不明显漏标/多标。公式结论正确而证明确定性错误、构造操作不能成立、搜索状态界排除合法样例等，均不能算题解正确。必要时用反例或小规模穷举核验。

joint_correct仅为两者逻辑与；每题最后一列为首测及三次二测4个joint之和，整数0–4。分数接近人工、模型自信或格式校验通过均不能替代语义复核。无法确定项须先补查，不能未经检查填真。

这属于代理复核，不是教师新增标签金标准或平台AC率，也不改正式审核。保留80条明细、原知识点及可见题解定位，便于用户复查。标准制定者读到长期记录中首测摘要，不能声称完全独立盲审；未见二测结果时先定标准。

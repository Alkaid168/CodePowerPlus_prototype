# 知识图谱的学习门槛、重要性与推荐策略研究

## 1. 结论

建议采用“硬先修关系 + 基础能力要求 + 学习难度档位 + 目标相关价值”四项信息，再结合用户证据选题。

用户提出的难度是必要补充：没有前驱的高阶知识点不应直接进入初学者的常规推荐。但难度只能提供初始判断，不能独自证明一个人能否学习，更不能替代尚未记录的基础要求。

重要性也应独立记录。它既不是难度，也不是图中的层数或后继数量；它取决于目标赛事中的应用机会、对后续知识的帮助，以及这位用户补齐它的成本。

推荐过程先回答“现在适不适合学”，再回答“此时最值得学什么”，最后选择能训练目标能力的具体题目。

## 2. 硬前驱究竟意味着什么

作者笔记的定义是：A 是 B 的前驱，意味着必须掌握 A，才可能掌握 B（对绝大部分正常学习者而言）。建议保留这个严格方向，但明确掌握的深度和路线。

- 必要性：在约定学习目标下，掌握 B 需要相应的 A 能力。
- 非充分性：掌握所有已标注前驱，不代表 B 已会，也不保证立即学得会。
- 能力与时间不同：需要 A 能力，不等于必须先单独学完一门名为 A 的课程；可以在学习 B 时补齐 A。
- 范围必须清楚：理解算法、独立实现、识别题型、解决变式，是不同学习目标。
- 特定实现依赖不能冒充所有路线的必要条件。线性构建笛卡尔树常用单调栈，不代表理解笛卡尔树定义必须先完整掌握单调栈题型。

在必要能力已充分细分、关系覆盖足够的简化模型中，拓扑顺序可以表示一种合理学习顺序；真实学习还包含并行补基础、复习、迁移及替代路线，拓扑排序不能承担全部推荐逻辑。

### 没有前驱的三种情况

1. 在明确约定的起始基础之上，确实可直接学习。
2. 所需基础属于数学、复杂度分析、代码实现等能力，未进入当前题目标签图。
3. 当前关系漏标，或者现有标签粒度太粗，无法准确表达必要基础。

所以入度为零只说明“本图没有记录前驱”。必须把“已检查且满足约定起始基础”和“尚未覆盖”分开。建议维护先修覆盖状态：未检查、部分覆盖、已按指定学习目标检查；它不能等同于难度或内容审核状态。

## 3. 三个现有根节点的具体分析

以下是依据现有词表与 OI Wiki 正文形成的需求分析候选，尚未作为教师审定关系写入图谱。

| 知识点 | 学习它仍需什么 | 为什么不能随意补一条宽泛硬边 | 推荐时如何处理 |
| --- | --- | --- | --- |
| 猫树 `ds.cat-tree` | 数组与区间；能理解满足结合律的信息合并；前后缀预处理；区间分解和时空复杂度。特定实现另需位运算定位等能力 | 先会线段树有帮助，但线段树的全部更新、懒标记等能力并非静态猫树的必要条件；结合律也不要求先学完整抽象代数 | 先诊断“能否用有序的前后缀合并回答跨中点查询”；基础满足后再看学习成本与目标应用 |
| 笛卡尔树 `ds.cartesian-tree` | 树与遍历顺序；按下标的有序性质、按权值的堆性质；线性构建阶段再要求单调栈思路与均摊分析 | BST 的查找/插入/删除整套操作、二叉堆的实现都不是这两种性质本身。树基础则是值得复核的真实缺边候选 | 分开“理解定义与性质”“线性构建”“转化 RMQ 等应用”；不能统一当成同一难度 |
| 反演变换 `geometry.inverse` | 圆、直线、距离、比例、代数变形；应用层还需相切、映射关系、退化情况及所选计算路线的数值能力 | 现有二维几何标签包含点积、叉积、方向判断等整套工具；整包并非每条反演学习路线的硬前置 | 先检查圆与距离基础，再用简单反演性质题进入；复杂相切构造与数值实现另设训练阶段 |

OI Wiki 的猫树正文以静态区间和昂贵合并操作说明价值，亦指出某些静态线性基场景有更优替代方法；这说明推荐需要考虑具体用途和替代方案。反演正文的例题把求相切圆转化为求公切线，说明“知道反演公式”和“能独立用它解题”相差很大。

基础能力清单可以作为图谱附属信息，不必把所有基础概念都扩充为题目标签或可视化圆球。若现有叶子确实能精确表达必要基础，才补经审核的硬边；若不精确，应拆清能力范围。

## 4. 怎样标难度

### 建议先做有锚点的粗分级

第一版可用五档：入门、基础、进阶、高阶、专题。它们表示在声明的起始基础和学习目标下的相对学习负担，不代表已测得的 Codeforces 分数。

每条标注至少附：

- 学习目标：理解、独立实现、典型应用，或综合迁移。
- 主要难点：概念/证明与建模/实现；初期可用文字说明，不必马上做三个精确数值。
- 起始基础与代表任务：用什么小任务判断具备入口能力，用什么陌生任务判断达到目标。
- 标注来源、置信程度、版本；机器初标与人工复核分开。

同一知识点可以有基础入门档和综合应用档；一个知识点也不必机械拆出四个独立可评分技能。只有能够收集有效证据的阶段才建立画像指标。

例如笛卡尔树“能画出符合两种性质的树”可以明显早于“在线性时间内构建并识别隐藏应用”；反演公式易记，不代表几何建模容易。不能将它们统统压成一个永久不变的门槛。

### 不建议直接设置精确、刚性的 CF 分数线

“低于 1800 禁止猫树”一类规则目前没有本项目数据支持，文献也不提供这种映射。总体 rating 会掩盖领域差异：总分相近的学生可能分别擅长数据结构和几何。

更合理的是：

1. 冷启动时，用总体水平和难度档位缩小范围；遇到高阶、基础覆盖不明的根节点，先降低常规推荐优先级。
2. 有可靠领域证据时，以对应基础掌握和诊断表现为主。总分偏低但相关基础扎实的人，可以进入该知识点。
3. 基础未知时提供短诊断或准备任务；未知不能当作零分。确实缺基础时推荐补齐路径。
4. 用户明确选择专题目标时，可以给出“先补什么、预计学习负担”的路线，不必永久封锁该主题。
5. 将来如有足够真实数据，再校准“在某能力区间、某种教学支持下进入该阶段的成功率”，并显示区间和不确定性。

题目难度、知识点学习难度、学习成本是不同量。带某标签题目的最低或平均 rating 不能直接充当知识点门槛：题目可能融合其他技能、存在替代方法，标签也可能漏标或粗标。

## 5. 怎样区分“网络流”和“猫树”的重要性

### 5.1 先确定目标与比较粒度

“网络流更重要”可以作为 ICPC 训练规划中待验证的专家判断，但不应泛化为所有赛事的实测结论。目标至少包含赛事/组别、能力区间、备赛时间。

具体反例：USACO Guide 的 Advanced 页面把 Maximum Flow、Minimum Cut 和 Minimum Cost Flow 标为 Rare，把 Flow with Lower Bounds 标为 Has Not Appeared。这是社区课程对其赛事语境的判断，并不是 ICPC 考频统计；但它足以说明不能使用一个通用重要性排名。

当前词表 `graph.flow` 是非叶子分类，包含最大流、费用流、上下界流等；猫树是单个叶子。比较整个分支和一个细分技巧容易放大差异。应分别比较叶子，或明确展示分支汇总。汇总考频使用相关题目的去重并集，不能把一道含多个流标签的题重复相加。

### 5.2 将重要性拆成三项

| 项目 | 回答的问题 | 建议取得方式 |
| --- | --- | --- |
| 直接应用价值 | 目标赛事中多大概率遇到适合使用它的题目？ | 先专家分“核心/常用/专题”，后按目标赛事题目语料统计 |
| 基础与迁移价值 | 学会它能帮助掌握哪些有价值的后续内容、形成什么通用能力？ | 结合经过审核的先修关系和专家说明；避免直接采用出度/PageRank |
| 学习成本 | 这位用户还要补什么、需要多少训练与实现投入？ | 结合已掌握基础、诊断、实际学习时间，先给粗档或区间 |

前三者是排序依据；最终的个人优先级还要结合掌握缺口、用户目标和剩余时间。已经很熟的高频知识点可能只需复习；尚未掌握的高频知识点也可能因准备成本过高而排在更可及的基础训练之后。

图中后继多不自动等于重要：图的覆盖与节点粒度不同，很多通用方法也未体现为硬边。迁移价值不应与直接考频重复计算；所有建议权重都要经真实验证。

### 5.3 怎样做可靠考频

定义一个明确的语料窗口，例如某些 ICPC 区域赛近若干年公开题目。数据选择只是研究设计示例，本轮没有采集出实测比例。

- 分母必须是同一范围内的题目/场次，不能拿自己的提交记录或题库收录数量代替。
- 同一道题跨站镜像去重，明确一个“出题机会”的单位。原始题面、官方题解和标签的覆盖率分别记录。
- 区分标准/主流解法、必要方法与可选替代方法。能用网络流暴力建模，不等于它在该场景应得到同等训练价值。
- 必要时同时给“含此方法的题目占比”和“至少出现一次的场次占比”；混合不同赛制、题量会改变解释。
- 平台没有“猫树”原生标签时，未标注是未知，不是零出现。应在统一语义下补标或人工抽样估计漏标。
- 给样本量、时间范围、缺失比例和不确定性；小样本可收缩到专家先验。简单示意为 `(命中数 + α) / (总数 + α + β)`，α、β 的来源必须声明，不能伪造精度。
- 近期权重可以用于备赛，但需保留未加权计数与明确计算版本。加权后的不确定性不能直接套未加权二项分布公式。

第一阶段不必等全量采集完成：可以先采用目标相关的专家课程优先级，并明确它不是实测考频。本轮没有获得可比较的网络流/猫树真实考频，不给出倍数或百分比。

## 6. 如何落实到画像和推荐题目

### 推荐流程

1. **确定目标。** ICPC 备赛、CF 提分、专题补强、课内基础，对应不同价值排序和时间预算。
2. **找当前入口。** 查询硬先修、基础能力清单和覆盖状态；用难度档位辅助冷启动。输出可学、需诊断、先补基础三类候选。
3. **选择训练目标。** 在可及候选中比较目标价值、掌握缺口、预计收益和学习成本；未知且可能重要的内容可安排诊断。
4. **匹配具体题目。** 按目标技能的训练阶段与实际解法选题，同时控制其他技能负担。高阶算法的简单入口题也可能适合有准备的学生，简单算法的综合难题也可能不适合。
5. **收集有效证据。** 结合独立实现、是否用提示、实际方法、陌生变式及延迟测验更新画像。一次题目 AC 不能给所有可选方法等额加分；失败也不能把所有关联知识点同时判不会。
6. **保留复习与探索。** 避免只推已擅长领域或只追最高考频；目标内容暂时不可及时，应推荐通向目标的准备任务。

第一版建议用透明规则与分档比较，不急着拼一个带任意权重的“最优总分”。例如同等可学、同等缺口时优先核心主题；明显缺基础时先补准备任务；用户主动专题目标优先于通用课程排序。冲突决策及原因应能解释和复查。

用于说明的假设案例（不是学生数据实验）：

- 只掌握语法的学生：猫树/反演即使没有图内前驱，也因基础清单未满足、学习负担高而不进入常规主推荐。
- 总 rating 不高、但区间预处理与结合律能力扎实，且有明确静态查询需求的学生：可以安排猫树入口任务，不被一个总分线永久排除。
- ICPC 图论基础扎实、最大流尚未系统掌握的学生：若目标课程将其列为核心，可优先于当前没有明确用途的猫树专题；这里依据是目标和缺口，不是假称本轮测出了考频。
- 流相关算法已熟、而目标题型确实需要静态复杂合并优化的学生：猫树可能具有更高的当前边际价值。

### 画像至少区分什么

知识点掌握程度、证据可信程度、学习阶段、基础缺口分别表达；总体/领域水平仅作背景信号。节点难度属于内容属性，用户准备程度属于人和内容的关系，两者不能共用一个字段。

推荐解释可以直接说：“你已具备区间分解与前后缀合并基础；这组题用于学习静态查询优化。”若证据不足，则说需要先确认哪一项能力，不能把图上路径当作已发生学习记录。

## 7. 三种可行方案

| 方案 | 内容 | 优点 | 局限及适用阶段 |
| --- | --- | --- | --- |
| A：难度 + 目标重要性 | 保留现图，每点粗难度，每类目标课程优先级 | 成本低，能快速挡住明显过难内容 | 漏基础未解决；总分容易误判偏科用户。适合作为基线 |
| B：A + 基础清单 + 分阶段证据 | 根节点与高阶节点先审基础要求，诊断补未知，用可解释规则选题 | 同时解决入口、适学性与收益；容易逐项审查 | 需维护内容并设计真实诊断任务。建议作为下一阶段主方案 |
| C：B + 自适应学习收益优化 | 积累真实训练结果后，用情境多臂老虎机等方法调整候选优先级 | 可从实际学习进展中纠正初始估计并探索 | 冷启动、反馈归因、选择偏差与实验评估复杂；不建议直接上线替代 B |

教育研究给出方法参考：Clement 等的 RiARiT/ZPDES 将经验学习进展、探索利用与专家约束结合；其摘要报告的是 7–8 岁儿童的金钱分解学习任务及模拟实验，不是算法竞赛结论。可借鉴“专家给起点与约束、数据逐步修正”，不能据此承诺本项目收益。

Sweller 的认知负荷研究支持注意任务要素之间的交互及教学方式，不能推出某算法固定对应多少 CF 分。Rafferty 等指出自适应实验分配会影响统计推断，不能将自适应推荐后的观察均值直接当作无偏教学收益。

## 8. 建议的实施顺序与验收

本轮仅研究，下列尚待范围确认与具体设计：

1. 确认首个目标赛事/人群，约定基础/进阶/综合应用等学习深度。
2. 先选三个问题根节点及若干常用对照知识点，整理基础清单、粗难度和目标课程优先级；保留来源/覆盖状态，不立即全量精确评分。
3. 为入口能力与独立迁移设计代表任务，由负责人/教师审核；这是要实际完成的内容工作，不能拿机器自评代替。
4. 用同一题库与用户证据对照图谱基线、加难度、再加基础与目标价值，检查每一步是否改善。
5. 积累真实数据后再做评分区间校准、目标考频统计及收益学习。涉及画像和方法归因时与现有动态评分契约一起设计，不能只在图谱 UI 上加数字。

验收分开进行：

- 内容：先修覆盖、基础要求是否准确，难度档位的一致性与代表任务是否匹配。
- 适学：被判为可学的人是否真的具备入口能力；高阶根节点误推是否下降；偏科但具备基础的人是否被误挡。
- 教学：相同时间内陌生题迁移、延迟保持、提示依赖与挫败情况，而不只看即时 AC 或点击率。
- 实验：题目/镜像/重复提交去重，按用户和时间隔离，防止未来信息泄漏；目标群体、样本量、掉队和选择机制明确报告。预测准确不自动证明推荐促进学习。

## 易混淆条件的处理

- P1803 的端点相接可连续参加，由官方样例 `0 2`、`2 4` 的答案为 2 直接核对。
- P1440 官方描述的个别措辞容易被理解为包含当前项，但官方输出格式明确为“之前”，样例也排除当前项；重述明确区间为 $[\max(1,i-m),i-1]$。
- P3370 的官方全数据范围写 $N\le10000$、$M_i\approx1000$、$M_{\max}\le1500$；重述保留近似规模说明，没有把它误写成每串恰长 1000，也未凭记忆增设官方未列出的精确下界。
- P3372 保留正初值、正增量及任意时刻总和上界 $2\times10^{18}$，不能仅以原始元素范围描述溢出风险。
- P3386 允许重边；P3390 允许负矩阵元素和零指数，两题各有两组官方样例，全部保留。
- P1880 是环形、累计得分，要求同时求最小和最大；P1352 只输入 $n-1$ 条关系，没有旧版本常见的额外 `0 0` 终止行。
- 运行限制从官方 `limits` 获取，内存保留原数值并标明 KiB，未把 128000 KiB 四舍五入成 128 MiB。各题所见所有测试点具有相同的时间和内存限制。

# C 语言新生语法标签与难度边界（2026-10-16）

## 已批准的范围与版本兼容

词表版本从 `2026.09.9` 升为 `2026.10.1`。新增一级领域 `syntax`（语法基础），原 `basic` 仅将展示名称从“基础”改为“算法基础”。原有 345 个节点的 ID、层级、父节点、介绍和其他字段保留；新增 32 个节点后合计 377 个节点：10 个一级领域、7 个新二级章节和 24 个新三级标签。这里的“原有节点”包括算法基础、数学等所有既有领域。

`data/knowledge_taxonomy.json` 是当前词表，`data/taxonomy_versions/2026.10.1.json` 是内容相同的新快照。`2026.09.9.json` 和更早快照保留原样，旧分析的版本和标签不自动迁移。

一级领域只作组织和统计，不能直接作为题目标签。新语法章节和叶子均带可选整数元数据 `intro_rating`，表示这个知识点开始适用的最低入门阶段；一级 `syntax` 不带该字段。旧算法节点不补写这一字段，避免改变历史节点内容。

## 七个阶段

| 门槛 | 二级 ID / 章节 | 三级标签（ID 后缀） |
| --- | --- | --- |
| 100 | `syntax.output` / 输出 | 固定文本输出 `literal-output`；转义字符与排版输出 `escape-output` |
| 200 | `syntax.variables-io` / 变量与输入输出 | 变量赋值与基本类型 `variables`；基本数值输入输出 `numeric-input`；数值格式控制 `formatted-output` |
| 300 | `syntax.expressions` / 表达式运算 | 四则运算与简单公式 `arithmetic`；整数除法与取余 `division-remainder`；数值类型转换 `conversion` |
| 400 | `syntax.conditions` / 条件分支 | 关系比较与单分支 `comparison`；逻辑条件组合 `logical-condition`；多分支分类讨论 `multi-branch` |
| 500 | `syntax.loops-arrays` / 循环与数组 | 循环控制与终止 `for-while`；循环累加与统计 `loop-accumulation`；数组读写与遍历 `array-traversal`；数组元素修改与搬移 `array-basic-update`；嵌套循环与简单图案 `nested-loop` |
| 600 | `syntax.characters-strings` / 字符与字符串 | 字符判断与大小写转换 `char-classification`；字符数组与字符串输入输出 `string-input`；字符串遍历与字符统计 `string-traversal`；字符串比较与基础变换 `string-comparison` |
| 700 | `syntax.basic-integration` / 基础综合与数学 | 数位拆分与循环综合 `digit-loop`；基础因数试除 `divisor-trial`；基础质数试除 `prime-trial`；多重循环条件综合 `loop-integration` |

三级完整 ID 为二级 ID 加点和后缀，例如 `syntax.basic-integration.prime-trial`。每章的全部三级标签采用该章门槛。各章节有 2–5 个叶子，全部新二三级节点有独立的中文介绍，解释适用题型、注意事项和与算法标签的边界。

这七个分值是项目为 C 语言新生确定的教学刻度，不是 CS50 或其他外部课程给出的分级，也不是通过学生作答校准的测量结果。700 以下的入门段只使用 `syntax` 下的标签；原有普通算法知识从 800 起进入算法难度范围。

## 按必要解法标注，不按代码中的语法词打分

`intro_rating=500` 表示该标签不会用于 100–400 的题，不表示只要出现数组，这道题就必须是 500。数组可以只是实现手段；完整约束下所需的算法仍决定题目应该进入哪个范围。标签的门槛是下限，不是题目最终评分，也不代表学生已经掌握该知识。

| 题目核心要求 | 典型标注边界 |
| --- | --- |
| 无输入，打印 Hello World | 100，固定文本输出 |
| 输入两个数，输出 A+B | 300，四则运算；读取数字只是配套步骤 |
| 顺次读入若干数求总和 | 500，循环累加与统计；无需强贴数组或前缀和 |
| 直接反转一段短文本 | 600，字符串比较与基础变换；不贴高级字符串算法 |
| 逐位拆分十进制数求数位和 | 700，数位拆分与循环综合；不自动贴数位 DP 或进制转换 |
| 对小规模单个整数试除判断质数 | 700，基础质数试除；不自动贴原数学领域的素数与筛法 |
| 求一段大范围内全部质数，约束要求筛法 | 普通算法范围，使用原 `math.number-theory.sieve` 等适用标签 |
| 数组上多次区间求和，必须使用前缀和 | 普通算法范围，使用原 `basic.prefix-sum`，不因出现数组而评成 500 |

700 的小学数学边界覆盖能直接由整除、余数与循环实现的任务。试除可只检查到平方根并成对处理因数；这仍与大范围筛法、快速素性测试、乘法函数、数论定理等原有算法标签分开。多重循环综合只涵盖小范围条件列举，复杂剪枝或状态搜索使用原算法领域。

不新增安装环境、编译、调试、IDE 操作等工具标签。函数、指针、结构体、文件处理等内容也未因 C 语言完整性而机械加入；本次词表面向已批准的 100–700 入门题型，后续扩展应由真实标注需求决定。

## 公开资料与独立整理

以下资料于 2026-10-16 通过其官方页面查阅，用于核对基础概念和教学组织。中文节点介绍由本项目独立撰写，未复制课程原文或沿用课程专有输入接口。章节顺序、标签粒度、评分边界及小规模试除综合的安排属于项目设计，不能归为来源的原始结论。

- [Harvard CS50 官方 Lecture 1: C](https://cs50.harvard.edu/x/2026/notes/1/)：核对固定输出、格式说明、变量、条件、循环和表达式等基础概念。项目将这些内容拆为可直接标注题目的节点，不照搬其工具使用内容。
- [Harvard CS50 官方 Lecture 2: Arrays](https://cs50.harvard.edu/x/2026/notes/2/)：核对数组逐项访问、字符与字符串的关系及结束标记。CS50 示例中的 `string` 和部分输入函数依赖课程库，本项目面向标准 C 的字符数组与输入输出。
- [Microsoft C 运行库 scanf 官方参考](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/scanf-scanf-l-wscanf-wscanf-l?view=msvc-170)：核对格式化输入、目标参数和字符串输入宽度的注意事项；项目不要求采用厂商扩展接口。

未使用学校私有题目、教师评分或学生作答数据，没有据此宣称难度得到实证校准。后续可用真实课程样题与人工评审检验节点是否遗漏、门槛是否合适，并区分教师判断与机器建议。

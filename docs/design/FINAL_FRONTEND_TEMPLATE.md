状态：**总览、知识树、题目录入与分析、题目详情、题目库、审核队列与独立审核页已按最新要求实现；全局外壳与组件规范已确认。其他业务页面尚未逐个完成最终布局。**

## 0. 后续对话使用协议

1. 开始前端 UI 任务前，先完整阅读本文件、`tokens.json`、`foundations.md`、`components.md` 和 `motion.md`。
2. 最新用户说明优先于本文件；如果用户确认了新要求，必须同步更新本文件，避免下一次对话使用旧规则。
3. 当前阶段优先实现样式和视觉结构，不新增业务逻辑，除非用户明确要求。
4. 不要恢复已明确删除的旧元素，包括顶部栏、侧栏分组标题、侧栏底部状态、黑色 Hero、主卡右侧灰色小卡和 Logo。
5. 不要重新定义第二套颜色、圆角、边框、阴影或动效 token。
6. 其他页面可以复用总览外壳和组件规范，但不能把总览的业务结构机械复制到所有页面。

## 1. 产品与视觉方向

- 形态：浏览器内全屏桌面工作台，不是原生桌面窗口。
- 气质：明亮、通透、克制，接近 macOS 与 visionOS 的秩序感。
- 参考：借鉴 `https://xept.online/projects` 的控件尺度、留白、边界和信息密度，不复制其品牌或业务。
- 主色：白色、黑色、标准灰。彩色只用于语义状态。
- 风格：简洁、大气、平滑，有足够明显的悬停和进入动效，但不做无意义漂浮。
- 禁止：渐变、紫色品牌色、蓝紫光晕、玻璃高光、厚重黑块、胶囊化卡片。

## 2. 全局工作台外壳

### 2.1 布局

- 普通页面只占位 `80px` 图标栏，不额外预留空白。鼠标移入展开为 260px、移出收起，展开覆盖正文，主体位置保持不变。
- 侧栏采用已有浅灰表面 `#FAFAFA` 与很轻的右侧内阴影，和 `#F5F5F5` 主画布及白色卡片稍作区分，不引入新品牌色。
- 题目详情 `#/problems/:id`、专用编辑 `#/problems/:id/edit` 和单题审核 `#/reviews/:id` 完全隐藏侧栏与 Logo，主体使用整个窗口宽度，加载与失败状态也保持相同布局。
- 左侧栏固定，不随主体滚动。
- 不设置顶部栏。
- 页面标题直接进入主体首行，不显示 `DASHBOARD` 等英文眉题。
- 只有主体 `main` 独立滚动；侧栏不滚出视口。
- 主体内边距：`30px 34px 36px`。
- 标准桌面 `1440×900`：总览必须完整放下，不出现主体滚动条。
- `1280×800`：总览同样必须完整放下。
- `1024px` 及更窄：允许主体纵向滚动，但不得出现横向溢出。

### 2.2 品牌区

- 左上角使用透明 Logo：`/static/assets/codepowerplus-mark.png`。
- Logo 尺寸：约 `48×36px`，`object-fit: contain`。
- 收缩状态只显示 Logo；展开时 Logo 右侧显示英文 `CodePowerPlus`。
- 不显示中文品牌名，不显示“智能编程辅导系统”。
- 艺术字体尚未最终确定；只修改 CSS 变量 `--wordmark-font`，不要擅自换文案。
- 当前占位字体栈：`Avenir Next`, `SF Pro Rounded`, `Segoe UI`, sans-serif。

### 2.3 左侧导航

- 只保留关键功能入口，不显示“工作台”“训练与研究”等分组标题。
- 默认仅显示所有功能图标，文字在展开时显示。图标位置始终不变，选中图标为黑色圆角背景；展开后背景延伸覆盖该行。
- 鼠标 Hover 只在精确指针环境展开；键盘 focus-visible 时即时展开，焦点移出后收起。所有图标保留中文 aria-label，触屏可直接使用图标入口。
- 导航保持固定竖栏；窄屏不恢复旧的顶部横向列表。低高度允许图标区域滚动，隐藏滚动条。
- 不显示“当前学习者”“知识体系版本”“模型已配置”等底部信息。
- 导航字号：`14px`。
- 导航字重：`400`。
- 行高：`44px`。
- 图标：`18px`，线性图标，与文字左对齐。
- 普通文字颜色：`#111111`。
- 激活项：黑底白字，圆角 `8px`。
- Hover：浅灰背景 `#F1F1F1`，不位移超过 `1px`。
- 导航不做胶囊追逐动画，不播放整页滑动动画。

### 4.2 圆角

| 元素 | 圆角 |
| --- | --- |
| 输入框、按钮 | `8px` |
| 小按钮、标签、树节点 | `6px` |
| 普通卡片 | `12px` |
| 大面板、Modal | `16px` |
| 状态标签 | `9px` |
| 知识树等级标记 | `5px` |

不要把普通卡片做成胶囊或超大圆角。

### 4.3 阴影

- 普通卡片：`0 10px 28px rgba(0,0,0,.045)` 或更轻。
- 总览主卡：`0 16px 42px rgba(0,0,0,.055)`。
- Hover 抬升：最多 `translateY(-2px)`，阴影不超过 `0 20px 48px rgba(0,0,0,.07)`。
- 禁止彩色阴影、蓝紫光晕和厚重玻璃光圈。

## 5. 通用组件最终规范

### 5.1 按钮

| 类型 | 背景 | 文字 | 边框 | 用途 |
| --- | --- | --- | --- | --- |
| Primary | `#111111` | `#FFFFFF` | `1px #111111` | 当前区域主动作 |
| Secondary | `#FFFFFF` | `#111111` | `1px #BDBDBD` | 次要动作 |
| Ghost | 透明 | `#555555` | 透明 | 低优先级动作 |
| Danger | `#B3261E` | `#FFFFFF` | 同背景 | 确认后的破坏性动作 |

交互：

- Primary Hover：背景和边界变为 `#000000`，文字保持白色。
- Secondary Hover：背景 `#F1F1F1`，边界仍为 `#BDBDBD`。
- Press：`scale(.975)`，时长 `100–120ms`。
- Focus-visible：单层 `2px #111111` outline，offset `2px`。
- Disabled：浅灰背景、浅灰边界、灰色文字，不响应 Hover。
- 一个视觉区域最多一个 Primary 按钮。
- Primary 保持黑底白字，不要因为主卡改成白色就把按钮也改成白底。

### 5.2 输入类控件

- 单行输入高度：`42–44px`。
- 文本域最小高度：`88–96px`。
- 默认：白底、`2px solid #E0E0E0`。
- Hover：白底、`2px solid #BDBDBD`。
- Focus：白底、单层 `2px solid #111111`。
- Disabled：浅灰背景、浅灰边界、灰色文字。
- Focus 不得同时出现 border、outline 和 box-shadow 两层以上。
- 所有可编辑控件默认白底；灰底只用于禁用状态。

### 5.3 Checkbox / Radio

- 尺寸：`20px`。
- 可编辑：白底、灰色边界。
- 选中：黑底白标。
- Hover：边界加深。
- Disabled：浅灰底、浅灰边界、灰色说明文字。

### 5.4 Slider

- 右侧未填充轨道：细灰色，约 `2px #D7D7D7`。
- 左侧已填充轨道：稍粗黑色，约 `6px #111111`。
- 圆点：`20px` 黑色，外围 `3px` 白色。
- 左右轨道与圆点垂直居中。
- 数值实时可见，不使用渐变轨道。

### 5.5 卡片

- 背景：白色。
- 边框：`1px #E0E0E0`。
- 圆角：`12px`。
- 阴影：轻，不能压过边界。
- 内边距：普通卡片 `16–24px`。
- 卡片只保留标题、关键信息、数值和操作；减少重复解释小字。
- 静态数据卡原则上不移动；总览指标卡允许 `translateY(-2px)` 和边界加深。
- 所有卡片进入页面时播放 `card-enter`。
- 减少动态时改为 `card-fade`，只保留透明度。

### 5.6 标签、状态、表格

- 普通标签：浅灰底、深灰字、内容自适应宽度。
- 状态标签：文字和图标居中，宽度由内容决定，右边界统一。
- AC/WA/TLE/CE 等状态才使用功能色。
- 表头浅灰，数据行薄分割线；Hover 只改变背景，不改变行高。
- 禁止状态标签固定宽度导致文字偏移。

### 5.7 知识树

知识树采用 OI Wiki 式的 L1 顶部导航，不显示独立页面标题。

- 顶部横向排列全部十个 L1 领域，当前领域用黑色文字、加粗和底部黑线标识。语法基础位于算法基础之前；导航空间不足时可横向浏览，不挤压右侧搜索或产生页面横向溢出。
- 搜索框位于 L1 导航同一行最右侧，提示文字固定为“搜索知识点”。
- 左侧列表只显示当前 L1 下的 L2/L3，不再出现 L1 行。
- 所有树条目都是白色长条、浅灰边界和 `6px` 圆角；不使用黑、灰、白分级底色。
- 不显示 L1/L2/L3 等级标注。
- 箭头使用 CSS 绘制，叶子使用 4px 圆点。
- L3 条目整体向右缩进 `18px`，箭头、圆点和长条左端点一起偏移，不只移动文字。
- 行高约 `38px`，文字 `12.5px / 560`。
- 选中条目保持白底，通过黑色边界和左侧 3px 黑线表示，不使用黑色填充。

#### 5.7.1 知识树页面布局

- 页面主体使用左树右详情双栏；左栏 `340–390px`，右栏自适应。
- 1440×900、1280×800 下两栏各自滚动，页面主体不滚动。
- 搜索使用缓存全树做本地过滤，结果显示完整路径，不重复请求后端。
- 1024px 及更窄宽度改为上下堆叠，允许主体纵向滚动，但不得出现横向溢出。
- 右侧详情不显示 L1/L2/L3 标签、英文 ID 或“可作题目标签”说明。
- L1 详情卡片不显示路径导航和下级目录，只显示名称与一张黑色线条知识插画。
- L2/L3 详情保留可点击路径。
- 详情响应进入渲染前必须把 `ancestors` 和 `children` 规范化为数组，避免字段缺失导致运行时错误。
- L2/L3 叶子节点都显示“知识点介绍”和 `summary`；有下级的节点只显示下级列表。
- 有下级时，列表直接位于标题下方，不显示“下级节点”标题，也不在标题与列表之间绘制贯穿横线。
- 下级节点不使用气泡卡片，直接铺在详情面板中，以横向分隔线区分。
- L1 插画使用代码原生 SVG，画布 `240×160`、透明背景、黑色 `currentColor` 线条，宽度不超过 `380px`。
- 一级领域插画统一采用简洁几何线稿：主轮廓约 `1.7px`，辅助线约 `1px`，通过线宽和灰度区分结构，节点留白、文字清晰。
- 十个领域的图形分别为：语法基础—终端与代码线稿；算法基础—排序柱列；搜索—八皇后棋盘；动态规划—数字三角形与高亮路径（不使用爬楼梯）；字符串—字典树；数学—圆与直角三角形；数据结构—二叉搜索树；图论—带权图与路径；计算几何—点集与凸包；杂项—滑动窗口。
- 语法基础详情和其他领域保持一致，不显示“入门门槛 · N”等评分提示；门槛仍在后台用于校验标签，不作为知识树页面文案。
- L3 叶子保留“知识点介绍”和 `summary`。
### 5.8 代码框

- 外框白底、`1px #E0E0E0`、圆角 `8px`。
- 顶部栏浅灰，高度约 `34px`。
- 左上角窗口点使用 macOS 彩色：`#FF5F57`、`#FEBC2E`、`#28C840`。
- 代码正文白底、深灰文字、黑色关键字、灰色注释。
- 使用等宽字体，行高约 `1.7`。

### 5.9 题目录入与分析页面

页面名称为「题目录入与分析」（早期叫「题目分析」，已废弃），是左侧录入、右侧结果的
双栏工作台，不再使用通用 `card + table` 的旧布局。

- 主体使用左录入右结果双栏：左栏 `360–440px`，右栏自适应。
- 1440×900 与 1280×800 下两栏各自滚动，页面主体不滚动；1024px 及更窄改为上下堆叠。
- 左栏在「新建」模式下是录入表单：标题、来源链接（可选）、题面 Markdown 文本域、主按钮「保存并分析」。
- 题面文本域使用等宽字体，占据左栏剩余高度，可纵向拉伸。
- 左栏在「已有题目」模式下显示编号、来源链接、标题、题面原文与「重新调用模型分析」。
- 新建与已有题目的表单中，「参考题解（可选）」和「参考代码（可选）」分别作为普通字段平铺，默认可见，不使用折叠区。内容超出左栏高度时由左栏滚动，不能压缩题面造成字段重叠。
- 新建表单在桌面填满左栏剩余高度：去掉字段重复外边距，三个文本域按剩余空间分配高度。底部提示、报错、重试按钮和恢复说明占据表单内的反馈行，出现时文本域适度收紧，不能把左侧卡片撑出滚动条。窄屏恢复自然高度和纵向滚动。
- 题目编号显示为 `#1000` 形式的等宽数字，紧跟来源链接与录入时间。
- 右栏在新建模式下是实时题面预览，输入停顿约 `500ms` 后重渲染。
- 新建预览标题旁不显示“开始输入题面后这里会实时渲染 Markdown 与 LaTeX 公式”；输入后的字符数与公式加载异常提示保留。
- 新建输入、题目信息修改与手工标注使用本浏览器草稿，450ms 自动保存，切页／刷新同步保存末尾输入；同用户／题号／上下文隔离，不代替服务端保存。
- 草稿状态仅在卡片标题右侧显示约 28px 的灰色图标，不显示自动保存文字、Toast 或持续动画。通过图标形状区分保存中、已保存与异常；title／aria-label 提供说明。旧版本草稿只提供导出图标，不覆盖新版输入。
- 右栏在已有题目模式下使用 Tabs：`分析结果 / 题面预览 / 手工标注 / 版本历史`。
- Tabs 容器 `#F1F1F1`、内边距 `3px`、圆角 `8px`；单项高 `33px`、圆角 `6px`；激活项黑底白字。
- 难度显示为黑底白字标签，内容为 `评分 · 档位`（如 `1600 · 进阶`），不要写成 `3/5`。
- 分析结果按「核心考点 / 也涉及 / 解题思路」组织，知识条目之间用横向分隔线，不使用卡片。
- 每条知识条目显示名称、ID、置信度与证据句。
- 题面、解题思路用 Markdown 排版（`.markdown-body`），**不要**套用代码框。
- 公式由 MathJax 按需加载并输出 SVG；代码块内的 `$` 不参与公式排版。
- 详情面板底部显示模型名、提示词版本与词表版本，并保留「去审核」入口。

### 5.10 题目详情页面（2026-10-04）

- 顶部只显示题号与题名：灰色等宽题号约 `22px / 500`，黑色标题约 `28px / 680`。
- 桌面左侧白色题面卡片、右侧约 `288px` 的题目信息卡片，间距约 `22px`；窄屏上下排列。
- 正文 `15px / 1.85`、常规字重；分节标题约 `17px / 650`，段前约26px、段后10px。题目与审核共用题目描述、输入格式、输出格式、数据范围、样例等清晰层级；常见旧分节名称仅在展示时规范。
- 题目阅读页和审核题面均不显示“独立构造样例，非官方样例。”“官方样例，已逐字核对。”这两句；原始题面、编辑预览与样例来源核对记录保留。数学变量、范围和幂指数由题面中的LaTeX明确标记，不对任意用户文本猜测数学语法。
- 难度、难度说明、核心／涉及标签、标注证据、来源和维护操作集中在右侧；说明与证据使用灰色 `12px / 1.8`，不能抢占题面视觉焦点。
- 不显示录入时间、记录提交、两个返回列表按钮、整体置信度、模型来源、知识版本和查看分析历史按钮。
- 题目库中的题名与查看使用原生新标签页链接，保留题目列表所在标签页。
- 右侧信息卡最下方固定提供白色次按钮“去编辑”，在当前标签页进入该题专用编辑地址；已有手工标注、去审核入口保持原样。
- 三个维护入口使用不同的同系列线性图标：手工标注为标签、去审核为勾选清单、去编辑为方框铅笔；尺寸和图文间距统一，不重复借用同一图标或留空。
- 相邻的样例输入／输出代码块在桌面并排展示，窄屏上下排列；只调整渲染结构，不修改题面原文。
- 代码框右上角复制图标在悬停或键盘聚焦时出现，触屏常显；复制保留原始换行，成功后显示对勾和轻量提示，失败时明确提示。
- 不显示题面页面、代码框或公式的滚动条，但保留长内容滚动与键盘操作；不要用截断内容来消除滚动条。
- MathJax 必须在题面容器挂载到文档之后排版，避免缓存引擎提前测量导致巨大公式。

#### 5.10.1 题目编辑页面（2026-10-16）

- 专用地址 `#/problems/:id/edit`，标题为灰色题号与“编辑题目”；右上方白色“查看题目”、黑色“保存修改”。不放全局侧栏。
- 桌面两张等宽白卡：左边五字段编辑，右边预览。标题与可选来源并排，题面占主要编辑空间，参考题解／参考代码（可选）默认平铺在下方。右侧可切换题面／参考题解／参考代码，沿用Markdown与LaTeX排版。
- 使用既有控件和黑白灰token；面板／输入框隐藏滚动条但保留内容滚动。窄屏上下排列，字段改单列，不横向溢出。
- 本地草稿只用标题旁小图标表示，沿用按用户／题号与版本隔离的草稿；与原分析页题目信息草稿互通，旧版本草稿可导出。
- 保存调用已有expected_revision接口，不调用模型；成功留在编辑页，可查看题目或前往更新分析。失败保留输入，冲突可加载最新版，原草稿保留；保存期间禁止重复提交及修改字段。

### 5.11 题目库页面（2026-10-04）

- 上方题目检索卡片仅保留三个控件与搜索按钮：题目搜索条、难度下拉框、算法标签多选入口。不显示“关键词”字样和“全部”按钮。
- 搜索空字符串且未限定筛选时显示全部题目；标题完全匹配／包含匹配优先，正文和当前算法标签其次。同优先级题号倒序。
- 难度使用当前十五个评分档位，保持原下拉框；100–700为七个单点评分，显示“基本运算 · 300”等形式，800以上原八档保持。算法入口显示“全部标签”或已选数量，打开白色分类多选弹窗：顶部分类导航与全树搜索、已选标签区、中部按知识领域与分支排列的标签按钮、底部取消和确认筛选。
- 弹窗使用现有中文知识名，保留常用算法英文缩写；支持中英文全树搜索、方向键定位／回车切换、已选移除和清空。标签选中为黑底白字；大类包含其下级，多个标签按“同时包含”筛选，组合在分页前执行。
- 选择仅修改草稿，确认后应用并回首页；取消、关闭、Escape 或遮罩关闭不更改已应用条件。原生 dialog 限定焦点，关闭后回到入口。
- 白色列表卡片显示题号、题名、中文标签、难度、分析状态、简短录入日期和查看；标题列优先分配宽度，标签自然换行。题名和查看继续新标签页打开。
- 底部分页含总题数、每页 `10 / 20 / 50 / 100` 题、上一页／下一页、当前页和页码按钮、直接输入页码跳转；页数多时省略中间页码。筛选或每页数量变化回到第一页，分页重绘后保留操作焦点。
- 不显示页面／标签弹窗滚动条，但保留正常滚动。弹窗标题、搜索、已选和确认区保持可用，中部标签区域滚动；已选区限制高度，不能撑大弹窗。窄屏分类横向滑动；极低高度允许弹窗整体滚动，确认区保持可达。窄屏检索控件换行，列表转为逐题上下阅读，不产生横向溢出。
- 区分“题库暂无题目”和“当前筛选无匹配”；请求失败提供重试，较早请求不能覆盖较新的筛选结果。

### 5.12 审核队列与独立审核页（2026-10-05）

- 队列使用一张白卡，仅保留状态切换、题号／题名／标签搜索、题目列表、页容量和页码。状态为待审核、已通过、已驳回；删除“旧版分析”入口，底层历史兼容保留。不展示内部知识证据规则长说明。
- 每题进入独立 `#/reviews/:id`。队列中的题名、审核／查看使用原生新标签页链接，保留队列所在标签页；独立审核页不显示顶部或底部返回队列入口。队列不展开题面或审核表单，题库与分析结果的去审核按钮直达单题。
- 单题页以灰色等宽题号、黑色题名开头；左栏题面、可选参考题解与参考代码，右栏分析标注和审核操作白卡。参考资料按页签切换，样例与代码支持悬停复制及反馈。
- 分析区按知识与难度、解题思路、审核记录分组。中文标签区分核心考点／也涉及，理由与证据为约 12px 灰色正文；不展示置信度、模型、版本等内部元信息。
- 默认只读，修改标注按需展开。下方审核人、可选意见、驳回和通过保持紧凑；编辑时主按钮为保存并通过。无待审核分析或题面已修订时收起审核表单，提供更新分析；已审核且无反馈时不保留空操作卡片。
- 桌面工作台按剩余高度布局，两侧长内容可滚动且无可见滚动条。1024px 及更窄改为上下阅读，720px 队列表格改逐题卡式布局；内容不截断，不产生横向溢出。
- 保持请求中防重复、失败草稿保留、冲突重载入口，队列切换状态不能显示旧请求结果；分页、状态与页容量重绘后保留键盘焦点。

## 6. 动效规范

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 按钮按下 | `100–120ms` | ease-out |
| Hover / 颜色 | `140–180ms` | ease |
| 卡片进入 | `280–300ms` | `--ease-out` |
| 页面内容切换 | `240–320ms` | ease-out |
| Modal / Drawer | `240–380ms` | ease-out / drawer |

- 卡片进入：`opacity 0 → 1`，`translateY(7px) → 0`。
- 多卡片入场按 `36ms` 递增延迟。
- Hover 只做颜色、边界、轻微阴影和最多 `2px` 位移。
- 禁止 `transition: all`。
- 禁止无意义持续漂浮、彩色 glow、背景扫光。
- `prefers-reduced-motion: reduce` 下取消位移，只保留短透明度反馈。
- 侧栏边缘展开／收回采用 `240ms` clip-path 与既有 ease-in-out 曲线，文字透明度保持约 160ms；不动画宽度／正文位移，键盘展开和减少动态模式不播放裁切变化。

## 7. 总览页最终结构

总览固定为 5 张卡片：

1. 三张指标卡：题目、待审核分析、提交记录。
2. 一张主建议 / 主题目卡。
3. 一张薄弱知识点卡。

不包含：

- 常用入口卡。
- 学习流程卡。
- 系统状态卡。
- 底部学习者、版本、模型信息。
- 重复说明小字。
- 模型密钥配置提示，包括“当前未配置模型密钥，可使用手工标注。”。

### 7.2 问候与操作

### 7.4 主建议卡

最终版必须是：

- 单一白色横向卡片。
- 不铺黑底。
- 不放右侧灰色小卡片。
- 不放右侧 Logo、掌握度环、“准备开始”或“今日训练”。
- 有题目时只保留题号、标题和操作按钮；空数据时保留“开始使用”标签。
- 内容垂直居中，左对齐。
- 卡片内边距：`38px 40px`。
- 卡片最小高度：`220px`；桌面网格为主卡保留至少 `260px`，剩余高度由主卡填满。
- 标题：`38px`、`700`、最大宽度约 `820px`。
- 标签与标题间距约 `20px`。
- 操作区距标题约 `32px`。
- 主卡按钮高度约 `44px`。

有题目状态：

- 不显示来源域名及独立标签；只显示 `#题目ID`，放在第一道题标题前。
- 题号为灰色等宽字体、`24px / 500`，与黑色 `38px / 700` 标题区分；两者横向间距约 `18px`，窄屏允许换行并缩小字号。
- 主按钮：`开始练习`，黑底白字。
- 次按钮：`查看题目分析`，白底灰边。

空数据状态：

- 标签：`开始使用`。
- 标题：`建立第一道题的学习记录`。
- 主按钮：`录入并分析题目`，黑底白字。
- 次按钮：`查看能力画像`，白底灰边。

### 7.5 薄弱知识点卡

- 白色卡片，最小高度约 `160px`。
- 标题：`薄弱知识点`，约 `18px / 680`。
- 有数据：知识点名称 + 黑色进度条 + 百分比。
- 空数据：`暂无做题证据` + Secondary 按钮 `查看能力画像`。
- 空数据内容横向排布，按钮右对齐。
- 不添加额外说明段落。

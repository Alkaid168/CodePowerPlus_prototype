# 40 道公开真题辅助评估

洛谷与 Codeforces 各 20 道，采用官方技术条件的独立中文重述，保留原题链接、采集核对记录和样例来源。当前已有题 #1000 的 P3374 来源未重复收集。

`luogu.json`、`codeforces.json` 保存题面与预测前独立辅助参考；`run-2026-10-05/manifest.json` 为冻结清单，`cf-reference-frozen.json` 是提前运行 CF 时冻结的原参考。参考标注由代理生成并核对，不是教师评审数据，不随模型预测调整。

CF 官方评分用于单独计算难度误差，官方标签保留作来源参考，不直接当作本项目标签金标准。洛谷官方等级不能冒充 CF 评分，其数值难度参考来自代理估计。CF 36 组官方样例已核对；洛谷 P1001 使用官方样例，其他 19 题使用独立算法检查过的自编样例，逐题明确标记来源。

模型只收到当前词表和重述题面，不收到来源 URL、平台评分、官方标签或辅助参考。公开经典题仍可能被模型记忆，结果不能外推到学校新题或教学效果。

## 运行与恢复

在项目根目录运行，模型配置沿用环境变量；不在文件内写密钥。

```powershell
# 只读已有有效输出并更新报告，不调用模型、不写题库
CodePowerPlus\Scripts\python.exe scripts\public_problem_batch.py

# 显式调用模型；有效断点会复用，失败项可续跑
CodePowerPlus\Scripts\python.exe scripts\public_problem_batch.py --analyze

# 必须全部分析有效才会备份并原子导入；不自动审核
CodePowerPlus\Scripts\python.exe scripts\public_problem_batch.py --import-db
```

两条路径都检查题面、来源、模型、词表和系统提示词的指纹，错配输出不能导入。已存在同来源但正文或分析冲突时拒绝整批导入；完全一致时跳过，不覆盖审核或学生记录。冻结清单变化需使用新的输出目录。

正式库备份位于 `%LOCALAPPDATA%\CodePowerPlus\backups`；`import.json` 记录备份与新题号。`predictions.json` 是真实模型输出和失败断点，`report.json`／`report.md` 是指标和逐题差异。任何参考或模型分析都不能自动成为“已通过”。
